Die zwei großen Paradigmen

Imperativ (Python)

"WIE wird es gelöst?"

# Schritt-für-Schritt Anweisung

for x in numbers:
    if x % 2 == 0:
        gerade_zahlen.append(x)

Deklarativ (SQL)

"WAS soll das Ergebnis sein?"

-- Beschreibung des Zielzustands
SELECT number
FROM numbers
WHERE number % 2 = 0;

Einzelfall vs. Generische Lösung

Ein guter Algorithmus sortiert nicht nur 3 Zahlen, sondern jede beliebige Liste.

def sortiere_liste(elemente: list) -> list:
    """Funktioniert für 3 oder 3.000.000 Elemente"""
    return sorted(elemente)

Qualitätsmerkmale von Code

Kurz aber unleserlich

# "Golfed" Code
f=lambda l:[x for x in l if x%2==0]

Clean Code (Wartbar)

def filter_even_numbers(numbers: list[int]) -> list[int]:
    """Filtert gerade Zahlen aus einer Liste."""
    return [num for num in numbers if num % 2 == 0]
