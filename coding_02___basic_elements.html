Variablen in Python

Was ist eine Variable?

Ein benannter Speicherplatz für Werte. Der Name ist frei wählbar (snake_case empfohlen).

# Zuweisung mit =
alter = 25
name = "Anna"
preis = 19.99

Dynamische Typisierung

Python erkennt den Datentyp automatisch zur Laufzeit.

x = 5       # Python weiß: int
x = "Hallo" # Jetzt ist x ein str

Grundlegende Datentypen & type()

Die 4 Basistypen

  • int: Ganzzahlen (42, -10)
  • float: Kommazahlen (3.14)
  • str: Text / Strings ("MCI")
  • bool: Wahrheitswerte (True, False)

Typ prüfen

alter = 22
pi = 3.1415
kurs = "Python"
aktiv = True

print(type(alter)) # 
print(type(pi))    #

Strings & f-Strings

Formatierte Strings (f-Strings)

Einfache Einbettung von Variablen direkt im Text mittels f"...".

name = "Maria"
punkte = 95

# f-String Auswertung zur Laufzeit:
nachricht = f"Hallo {name}, du hast {punkte} Punkte erreicht!"
print(nachricht)
# Output: Hallo Maria, du hast 95 Punkte erreicht!

Bedingungen: if / elif / else

Entscheidungslogik im Code

note = 2

if note == 1:
    print("Sehr gut")
elif note == 2:
    print("Gut")
elif note == 3:
    print("Befriedigend")
else:
    print("Bestanden oder Wiederholung")

Vergleiche & Einrückung

Vergleichsoperatoren

  • == (Gleich) | != (Ungleich)
  • >, <, >=, <=
  • Ergebnis ist immer ein bool (True/False)

Syntax-Regel: 4 Spaces

Einrückung definiert den Codeblock. Keine Tabulatoren mischen!

if x > 0:
    # 4 Leerzeichen Pflicht!
    print("Positiv")

Listen in Python

Was ist eine Liste?

Eine geordnete, veränderbare (mutable) Sammlung von Elementen.

# Erstellen einer Liste mit eckigen Klammern []
teilnehmer = ["Anna", "Ben", "Clara", "David"]
zahlen = [10, 20, 30, 40]
gemischt = [1, "Hallo", True, 3.14]

Indexing & Slicing

Indexing (0-basiert)

lst = ["A", "B", "C", "D"]

print(lst[0])   # "A" (Erstes Element)
print(lst[-1])  # "D" (Letztes Element)

Slicing [Start:Stopp]

# Stopp-Index ist exklusiv!
print(lst[1:3]) # ["B", "C"]
print(lst[:2])  # ["A", "B"]
print(lst[2:])  # ["C", "D"]

Wichtige Listen-Methoden

Elemente verändern & verwalten

fruechte = ["Apfel", "Banane"]

fruechte.append("Orange") # Hinzufügen -> ["Apfel", "Banane", "Orange"]
entfernt = fruechte.pop() # Letztes Element entfernen & zurückgeben
anzahl = len(fruechte)    # Länge der Liste -> 2
fruechte.sort()           # Alphabetisch/Numerisch sortieren

Typische Fehler bei Listen

Gefahrenstelle: IndexError & Off-by-one

Zugriffe außerhalb des gültigen Indexbereichs führen zum Programmabbruch:

zahlen = [1, 2, 3] # Indizes 0, 1, 2

# IndexError: list index out of range
print(zahlen[3])

Dictionaries

Schlüssel-Wert-Speicher (Key-Value)

Nachschlagetabelle für strukturierte Daten (wie ein reales Wörterbuch).

# Erstellung mit geschweiften Klammern {}
student = {
    "name": "Lukas",
    "matrikelnummer": 123456,
    "studiengang": "MCI"
}

Zugriff: Klammern vs. get()

Direkter Zugriff: d["key"]

print(student["name"]) # "Lukas"

# KeyError wenn Schlüssel fehlt!
print(student["alter"]) # Fehler!

Sicherer Zugriff: d.get()

# Gibt None oder Standardwert zurück
print(student.get("alter"))       # None
print(student.get("alter", 20))   # 20

Iteration über Dictionaries

Schlüssel und Werte durchlaufen

# Über Key-Value Paare iterieren:
for key, value in student.items():
    print(f"{key}: {value}")

Durchatmen & Netzwerken

Gleich startet der Endspurt mit Schleifen & List Comprehensions.

Schleifen: for

Iterieren über Sammlungen

„Für jedes Element in der Sammlung mache folgendes…“

staedte = ["Innsbruck", "Wien", "Salzburg"]

for stadt in staedte:
    print(f"Willkommen in {stadt}!")

range() & Akkumulatoren

Zahlenreihen mit range()

# range(5) erzeugt 0, 1, 2, 3, 4
for i in range(5):
    print(f"Durchlauf {i}")

Muster: Akkumulator

preise = [10, 20, 30]
summe = 0

for preis in preise:
    summe += preis # summe = summe + preis

print(f"Gesamt: {summe}") # 60

Typische Anwendungen

Zählen, Summieren & Filtern

zahlen = [1, 5, 8, 12, 15]
gefiltert = []

for z in zahlen:
    if z > 10:
        gefiltert.append(z)

print(gefiltert) # [12, 15]

Schleifen: while

Bedingungsgesteuerte Wiederholung

„Solange eine Bedingung erfüllt ist, führe den Code aus.“

counter = 3

while counter > 0:
    print(f"Countdown: {counter}")
    counter -= 1 # WICHTIG: Zustand ändern!

print("Start!")

Abbruch & Zustandsänderung

Gefahr von Endlosschleifen

Der Zustand in der Abbruchbedingung muss sich innerhalb der Schleife verändern!

# Endlosschleife (Vermeiden!):
# while True:
#     print("Stoppt nie")

Steuerung: break & continue

break: Schleife abbrechen

while True:
    eingabe = input("Beenden mit 'q': ")
    if eingabe == 'q':
        break # Verlässt die Schleife sofort

continue: Durchlauf überspringen

for i in range(5):
    if i == 2:
        continue # Überspringt 2
    print(i) # Druckt 0, 1, 3, 4

List Comprehensions

Klassische Schleife

zahlen = [1, 2, 3, 4]
quadrate = []

for x in zahlen:
    quadrate.append(x * x)

List Comprehension (Kompakt)

zahlen = [1, 2, 3, 4]

# Elegant in einer Zeile:
quadrate = [x * x for x in zahlen]

# Mit Bedingung:
gerade = [x for x in zahlen if x % 2 == 0]
